## 1. 서비스 개요

**가챠트립(GachaTrip)** 은 "여행을 뽑는다"는 컨셉의 랜덤 여행지 추천 모바일 앱이다.  
사용자가 여행 스타일, 예산, 출발지 등 조건을 설정하면, 가챠(뽑기) 애니메이션으로 여행지가 결정되고, AI가 맞춤 여행 코스(큐레이션)를 생성해준다. 개인/그룹 모드를 모두 지원하며, 여행 기록과 지도 형태의 마이트립 페이지를 통해 추억을 보관할 수 있다.

- **플랫폼**: iOS/Android 모바일 앱 + 웹 관리자 백오피스
- **주요 기술 키워드**: 랜덤 추천 알고리즘, AI 큐레이션(LLM), 실시간 그룹방(WebSocket), 소셜 로그인(카카오/Google/Apple)

## 2. 사용자 유형

| 구분 | 설명 |
|---|---|
| **일반 회원** | 개인 뽑기, 그룹 뽑기, 큐레이션 조회, 마이트립 관리 |
| **비회원** | 온보딩 열람, 소셜 회원가입/로그인 진행만 가능 |
| **관리자** | 웹 백오피스를 통해 여행지·가챠 정책·회원·콘텐츠·통계 전체 관리 |

### 4.1 온보딩 & 인증

#### SCREEN: 온보딩 슬라이드 (4단계)
- **화면 ID**: 온보딩-1 ~ 온보딩-4, 로고 스플래시
- **기능**:
  - 앱 최초 설치 시 4단계 온보딩 슬라이드 표시
  - "시작하기" 버튼으로 회원가입 화면 진입
  - 기존 계정 보유자 "로그인" 이동

---

#### SCREEN: 회원가입 (Sign Up)
- **화면 ID**: `06 · Sign Up`
- **입력 필드**:
  | 필드명 | 유효성 규칙 | 비고 |
  |---|---|---|
  | 닉네임 | 2~10자, 한글·영문·숫자 | Placeholder: "여행자 이름을 입력해주세요" |
  | 이메일 | 이메일 형식 | Placeholder: "example@gachatrip.app" |
  | 비밀번호 | 8자 이상 | Placeholder: "8자 이상 입력해주세요" |
- **소셜 로그인 버튼**: 카카오(노란색), Google(흰색), Apple(검정)
- **하단 링크**: "이미 계정이 있나요? 로그인"

---

#### SCREEN: 프로필 상세 설정 (마이페이지 진입 전 초기 설정 포함)
- **화면 ID**: `08 ~ 18` 시리즈 (Detail 설정)
- **설정 항목**:
  | 항목 | 내용 |
  |---|---|
  | 프로필 이미지 | 사진 터치로 변경 |
  | 닉네임 | 2~10자, 변경 주기 30일 제한 |
  | 한 줄 소개 | 자유 입력 |
  | 관심 여행 스타일 | 최대 2개 선택 (힐링 / 맛집 / 액티비티 / 감성) |
  | 자주 출발하는 지역 | 서울/경기, 강원도, 제주도 등 지역 선택 |
  | 예산 범위 | 범위 슬라이더 또는 옵션 선택 |
  | 추천 알림 | ON/OFF 토글 |
  | 위치 기반 추천 | 동의/비동의 |
  | 언어 | 한국어 등 |
  | 앱 버전 | 읽기 전용 표시 |

### 4.3 가챠 뽑기 - 개인 모드

#### SCREEN: 뽑기 시작 (모드 선택)
- 개인 뽑기 / 그룹 뽑기 중 선택하는 Bottom Sheet
- 각 모드에 아이콘 + 설명 문구 표시

#### SCREEN: 개인 뽑기 메인 (`03_개인뽑기-V2`)
- 뽑기 기계 그래픽 표시
- "조건 설정하기" 버튼으로 여행 조건 입력 진입
- "개인 뽑기 시작" CTA 버튼

#### SCREEN: 여행 조건 설정 (`09_개인 · 여행 조건`)
- **조건 항목**:
  | 항목 | 타입 | 선택 규칙 |
  |---|---|---|
  | 여행 스타일 | 태그 선택 | 1개 선택 |
  | 출발 지역 | 지역 선택 | 단일 |
  | 예산 | 범위 또는 옵션 | 단일 |
  | 여행 기간 | 당일치기 / 1박2일 / 2박3일 등 | 단일 |
  | 희망 여행지 | 텍스트 직접 입력 (선택 사항) | - |

#### SCREEN: 뽑기 중 (`04_개인 뽑기 중`)
- 뽑기 기계 애니메이션 재생 중 화면

#### SCREEN: 뽑기 결과 (`05_개인 뽑기 결과`)
- **표시 정보**: 여행지명, 지역 이미지, AI 설명문구, 해시태그 (예: #바다여행 #야경 #낭만)
- **Action 버튼**:
  | 버튼 | 동작 |
  |---|---|
  | 가본 곳이에요 | 해당 지역 후보 제외 → 새 여행지 재뽑기 |
  | 이 여행지로 확정하기 | 여행지 확정 화면 진입 |
  | 공유하기 | 공유 Bottom Sheet 표시 |

#### SCREEN: 공유하기 Bottom Sheet
- **공유 옵션**: 시스템 공유창(링크 복사) / 링크 복사 / 기타 앱으로 공유

#### SCREEN: 여행지 확정 (`07_뽑기 결과 확정`)
- 여행지 최종 확인 화면
- "이 여행지로 확정하기" CTA → "찐확정" 처리

#### SCREEN: 찐확정 (`08_뽑기 결과 찐확정`)
- 여행지 확정 완료 축하 화면
- **다음 Action 선택**:
  | 버튼 | 동작 |
  |---|---|
  | ✨ AI 여행 코스 만들기 | AI 큐레이션 생성 진입 |
  | 나중에 할게요 | 홈으로 이동 |

### 4.4 가챠 뽑기 - 그룹 모드

#### SCREEN: 그룹 시작 (`10_그룹 시작`)
- 개인/그룹 모드 선택 Bottom Sheet에서 그룹 선택 후 진입

#### SCREEN: 그룹 여행 조건 입력 (`11_그룹 여행 조건`)
- 그룹 공통 조건 입력 (여행 스타일, 기간, 예산)

#### SCREEN: 희망 여행지 입력 (`12_희망 여행지 입력`)
- 개인별 희망 여행지 텍스트 입력 (선택 사항)

#### SCREEN: 초대 링크 / 초대 코드 공유 (14~18)
- 링크 공유: URL 생성 + 공유 버튼
- 초대 코드: 6자리 코드 생성 및 표시
- 코드 직접 입력 진입 화면

#### SCREEN: 그룹방 대기실 (`13_그룹방 대기실`)
- 실시간 참여자 목록 표시 (접속 여부 도트 표시)
- 각 참여자별 희망 여행지/스타일 선택
- 방장: 미니게임 & 뽑기 시작 버튼 활성화 (전원 준비 완료 시)

#### SCREEN: 파티 미니게임 & 승자 가중치 부여 (`20_그룹 미니게임 & 뽑기`)
- **파티 미니게임 진행**: 순발력/탭/주사위 미니게임 진행
- **승자 가중치 적용**:
  - 미니게임 1등(승자)의 희망 여행지에 추첨권 3배수 가중치 부여
  - 일반 참여자의 희망 여행지/선호 지역 각 1배수 부여
- **가중치 룰렛 뽑기 애니메이션**: 그룹 전원 화면에 동시 동기화 추첨 연출

#### SCREEN: 그룹 뽑기 결과 및 투표 (`21_그룹 뽑기 결과`)
- 공동 추천 여행지 및 당첨 배경 표시 (예: "🎉 1등 OOO님의 희망지 당첨!")
- 그룹원 실시간 O/X 찬반 투표 (전원 찬성 시 최종 확정 / 재투표 / 재뽑기)

#### SCREEN: AI 랜덤 미션 (19, 22, 23)
- 뽑기 완료 후 선택적 기능
- AI가 여행 중 수행할 랜덤 미션 생성
- 미션 목록 확인 화면

### 4.5 AI 큐레이션

#### SCREEN: AI 큐레이션 홈 (`AI큐레이션_홈`)
- **섹션 구성**:
  | 섹션 | 내용 |
  |---|---|
  | 다가오는 여행 | D-Day 카드 형태, 해시태그, 날짜, AI 추천 장소 수 |
  | 저장된 여행 | 전체 / 예정 / 지난 여행 필터 탭 |
  | 여행 목록 카드 | 썸네일 + 지역명 + 날짜 + 기간 |

#### SCREEN: AI 여행 추천 상세

### 4.7 관리자 백오피스

> 대상 플랫폼: 웹 (1440px 기준) | 관리자 권한 필요

#### ADM-01: 대시보드
- 주요 지표 요약 카드 (활성 사용자, 일일 뽑기 수, 신규 가입 등)
- 그래프/차트 기반 통계

#### ADM-02: 여행지 관리
- 여행지 목록 테이블 (검색 / 필터)
- 여행지 등록 / 수정 / 비활성화

#### ADM-03: 뽑기 관리 (가챠 정책 & 파티 가중치)

**가챠 정책 관리 (`ADM-05 · 가챠 정책 관리`)**:
- **가챠 추첨 메커니즘**:
  - **개인 가챠**: 사용자 선택 조건(테마, 일정, 지역) 필터링 후 **100% 공평한 순수 랜덤 추첨** (의외성과 즉흥성 극대화)
  - **파티 가챠**: **파티 미니게임 승자(1등)의 희망 여행지에 추첨 가중치(추첨권 3배수)를 부여**하는 가중치 룰렛 방식
- **파티 가챠 가중치 설정**:
  | 구분 | 기본값 | 설명 |
  |---|---|---|
  | 미니게임 1등(승자) 티켓 수 | 3장 (60%) | 승자가 선택한 희망 여행지 우선 반영 |
  | 일반 파티원 티켓 수 | 각 1장 (각 20%) | 다른 파티원의 여행지도 반전으로 뽑힐 수 있는 긴장감 유지 |
- **제외·보정 규칙 토글**:
  - 최근 30일 방문지 제외 (재뽑기 도장깨기)
  - 운영 중단 여행지 제외
  - 당일치기 시 장거리/도서 지역 제외
  - 동일 지역 연속 추천 제한
- **정책 시뮬레이션**: 샘플 10,000회 실행 후 지역 분포 결과 확인
- **배포 버전 관리**: 현재 운영 버전 / 임시 저장 버전 / 이전 버전으로 롤백

**그룹 가챠방 모니터링 (`ADM-06 · 그룹 가챠방`)**:
- 실시간 활성 방 목록 테이블 (방 코드, 방장, 인원, 단계, 상태)
- 방 상태: 정상 / 대기 / 오류 / 주의
- 방 상세 패널: 참여자 목록, 진행 단계, 최근 이벤트 로그
- Action: 방 강제 종료 / 결과 재전송

#### ADM-04: 큐레이션 관리
- AI 생성 큐레이션 목록 관리
- 큐레이션 콘텐츠 검수 / 수정 / 숨김 처리

#### ADM-05: 회원 관리
- 회원 목록 검색 / 조회
- 계정 제재 (경고 / 정지 / 탈퇴 처리)
- 소셜 계정 연동 정보 확인

#### ADM-06: 콘텐츠 · 운영 (`ADM-07`)
- **탭 구성**:
  | 탭 | 내용 |
  |---|---|
  | 1:1 문의 | 미답변 건수 강조, 답변 처리 |
  | 신고 관리 | 신고 목록 / 처리 |
  | 공지사항 | 작성 / 수정 / 삭제 |
  | 큐레이션 | 큐레이션 콘텐츠 검수 |
- **지표 카드**: 전체 문의 수 / 미답변 수 / 24시간 초과 건수

#### ADM-07: 통계
- 가챠 사용량 추이 그래프
- 지역별 선호도 분포
- 기간별 필터 (일간 / 주간 / 월간)
